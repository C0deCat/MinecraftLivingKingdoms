# M1-A — World sizes, dimensions and the finite-world foundation

**Status:** Active

## Goal

A new world is created only through our size selector (Test / Small / Medium / Large, Large preselected). Each size generates a bounded Overworld with an outer ocean ring, a Nether at its per-size ratio, a 1:1 Twilight Forest and a bounded End, with borders matching [ADR-0004](../../decisions/ADR-0004-world-sizes-and-dimensions.md). Target level: runtime passed in singleplayer for every size, plus gameplay feedback from the user on the creation screen and the look of the coastline. M1-B (structure mods) and M1-C (manifest and validator) follow in later plans.
