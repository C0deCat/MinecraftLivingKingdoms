# Лицензии модов и правила использования

Справочник для решений «можно ли это включить, изменить, распространить». Это не юридическая консультация: при сомнении — спросить автора мода письменно (Discord, issues) и сохранить ответ здесь.

## 1. Общие правила

### Как распространяется сборка

- **Modrinth (`.mrpack`)** и **CurseForge** хранят в паке не JAR, а ссылки: лаунчер скачивает моды с площадки. Поэтому моды даже с закрытой лицензией обычно можно включать, если они лежат на той же площадке.
- **Modrinth:** моды не с Modrinth класть внутрь пака (overrides) можно только с разрешения автора.
- **CurseForge:** в пак попадают только моды с CurseForge, у которых автор разрешил сторонние модпаки.

### Уровни вмешательства

| Способ | Что распространяем | Риск |
| --- | --- | --- |
| Конфиги, датапаки, KubeJS | Свои файлы | Практически нет |
| Свой мод с Mixin-патчами чужого мода | Только свой код | Низкий: чужой код не распространяется. Хрупко при обновлениях |
| Форк открытого мода (MIT, LGPL, GPL) | Изменённый чужой код | Можно с условиями: GPL требует GPL и открытых исходников для форка |
| Форк закрытого мода (ARR) | Изменённый чужой код | **Нельзя** без разрешения автора |
| Переделка чужих ассетов | Изменённые структуры, текстуры, модели | Зависит от лицензии; ND-лицензии запрещают |

### Правила проекта

- Код закрытых модов не копируется и не декомпилируется в репозиторий (D-16).
- Платный доступ к сборке или её частям не планируется: часть лицензий (например, Millénaire) это прямо запрещает.
- Лицензия нашего мода, который глубоко использует код MCA Reborn (GPLv3), скорее всего, будет GPLv3.

## 3. Аудиты

### Millénaire

**Дата:** 2026-11-06 · **Итог:** в сборку не входит, используется только как источник идей.

- **Лицензия** (CurseForge): All rights reserved, но с разрешением включать в модпаки, если:
  - есть ссылка на страницу CurseForge, Discord или сайт мода;
  - указаны все авторы и мейнтейнеры;
  - баги сначала проверяются в сборке, а потом репортятся.
- **Запрещено:** выдавать мод за свой; ограничивать геймплей платой; перезаливать JAR на другие сайты (кроме «загрузок модпаков» — формулировка размытая).
- **Исходники:** закрыты. Ссылка «Source» ведёт на GitLab с контентными файлами (постройки, жители, языки, квесты), последний коммит в 2018 году, Java-кода нет.
- **Версии:** 9.0.3 (2026-10-21, NeoForge 21.1.226) — только на millenaire.org; на CurseForge — 9.0.2.
- **Расширяемость:** сабмоды через `millenaire-custom`; в 9.0.3 сабмоды могут подключать культуры, деревья и животных из других модов, свои культуры — своих NPC, но только с уже запрограммированными действиями.
