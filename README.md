# Living Kingdoms

A Minecraft 1.21.1 (NeoForge) fantasy pack that step by step turns into a game with a living world: a finite map, adventure, household life, magic, living villages built on MCA Reborn, states and a world that develops without players. Developed for singleplayer first; multiplayer (Open to LAN for 1–4 players, dedicated server) arrives in milestone M10, before release.

**Status:** M0 accepted in singleplayer. [M1 — World and adventure](docs/milestones/m1-world-and-adventure.md): step M1-A1 (base generator) done: four fixed world sizes, own size selector, per-dimension borders, natural world edge, Twilight Forest 1:1 ([ADR-0004](docs/decisions/ADR-0004-world-sizes-and-dimensions.md)). M1-A2 (structure and adventure mods) and M1-B (reconcile, renderer) done. In progress: M1-C, content manifest with its validator (done, no critical gaps on 12 test worlds; one client check pending), then the shader pack ([exec plan](docs/exec-plans/active/2026-11-09-m1-integrate.md)).
