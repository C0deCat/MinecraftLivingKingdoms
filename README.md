# Living Kingdoms

A Minecraft 1.21.1 (NeoForge) fantasy pack that step by step turns into a game with a living world: a finite map, adventure, household life, magic, living villages built on MCA Reborn, states and a world that develops without players. Developed for singleplayer first; multiplayer (Open to LAN for 1–4 players, dedicated server) arrives in milestone M10, before release.

**Status:** M0 and M1 accepted in singleplayer. [M1 — World and adventure](docs/milestones/m1-world-and-adventure.md): step M1-A1 (base generator) done: four fixed world sizes, own size selector, per-dimension borders, natural world edge, Twilight Forest 1:1 ([ADR-0004](docs/decisions/ADR-0004-world-sizes-and-dimensions.md)). M1-A2 (structure and adventure mods) and M1-B (reconcile, renderer) done. M1-C (content manifest with its validator, default shader pack) done. M1-D (acceptance) done 2026-11-10: 0 critical gaps on 12 validated worlds, progression gameplay verified on Large ([exec plan](docs/exec-plans/completed/2026-11-10-m1-accept.md)). Now: [M2 — Household](docs/milestones/m2-household.md), [M3 — Magic](docs/milestones/m3-magic.md) and [M4 — Settlements](docs/milestones/m4-settlements.md) in parallel tracks ([coordination plan](docs/exec-plans/active/2026-11-10-parallel-tracks.md)).
